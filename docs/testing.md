# Testing Checklist

- [ ] Navigasi sidebar desktop dan navigasi bawah mobile berfungsi.
- [ ] Beranda menampilkan ringkasan panduan, kalender, dan To-Do List.
- [ ] Kartu Panduan Belajar membuka halaman detail.
- [ ] Study Planner dapat berpindah bulan, memilih tanggal, menambah, dan menghapus jadwal.
- [ ] Pomodoro Timer dapat memilih tiga mode, start/pause, reset, dan mengubah durasi.
- [ ] To-Do List dapat menambah, menyelesaikan, dan menghapus tugas.
- [ ] Study Notes dapat menyimpan, membuka, dan menghapus catatan.
- [ ] Data tetap tersedia setelah halaman dimuat ulang pada browser yang sama.
- [ ] Halaman login menampilkan prototype tanpa mengklaim autentikasi aktif.
- [ ] Tampilan diuji pada lebar 360px, 768px, dan 1024px.
- [ ] Tidak ada horizontal scroll pada tampilan mobile.
